# ITFM v2 Project Contract

## Claim under test

When the complete visible context is compatible with two different futures, an
owner-safe external tensor memory can reuse a causally prior, spatially matched
innovation that lies outside the visible context window. If that information is
genuinely used, ordinary retrieval must improve forecasting, erasure must remove
the improvement, matched value swaps must move predictions toward the donor
future, and nuisance values must not reproduce the effect.

## Why v2 exists

ITFM v1 used noiseless constant-speed periodic translation with three visible
frames. Its analytical cross-correlation control could infer the shift from the
last two frames, so external memory had no unique information to contribute.
V2 does not overwrite or reinterpret v1. It changes the development question
before any v1 model fit completed.

## Development construction

Each independent family contains paired hidden regimes. At a calibration event,
the same spatial anchor leads to opposite zero-mean spatial innovations. The
realized target becomes observable only after prediction and may then be stored.
After a declared washout interval containing nuisance transitions, the same
anchor reappears as a query. The entire visible context is identical between
regimes, but the future again depends on the hidden regime. The earlier
calibration innovation is therefore useful, causally admissible information.

The primary memory:

- stores raw spatial context keys and observation-space residual tensors;
- enforces immutable owner identity and strictly earlier event time;
- excludes entries inside the visible context window;
- uses exact top-1 matching at development scale;
- combines retrieval with a frozen base predictor through a validation-only,
  bounded scalar coefficient;
- never receives hidden regime or anchor identifiers as model inputs.

## Falsifiers

V2 is negative or invalid if any of the following occurs:

1. Paired complete contexts differ at declared query events.
2. An analytical current-context control solves the query transition.
3. A past-only oracle memory lacks a material advantage over the frozen base.
4. Learned/fixed retrieval fails to recover at least half of the oracle gap.
5. Erasure does not remove the retrieval benefit.
6. Paired swaps do not move forecasts toward donor futures.
7. Sign-reversed, vector-broadcast, recent-only, or wrong-owner values reproduce
   the primary effect.
8. Non-query performance is materially degraded.
9. Any cross-owner, future-time, split, or artifact-integrity violation occurs.
10. The effect fails a later frozen public-domain partial-observation study.

## Evidence boundary

A passing synthetic development result establishes only that the reference
mechanism can store and causally reuse a spatial innovation under the declared
construction. It does not establish natural-domain superiority, state of the
art, universal memory benefit, publication novelty, or independent replication.
